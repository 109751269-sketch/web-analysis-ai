六、能力缺口

  • 评论覆盖仍不完整：按公司优先 + 尽力全量采集，四大专题 4.2 万帖不可能逐帖抓评论；目前先抓「目标公司相关帖 + 高评论数帖」。
  • 公司主页不可直达：脉脉公司页 404，只能靠专题/频道 feed 里筛 title，长尾公司声量天然偏低。
  • 「没有评价」不等于「口碑好」：中小/国企雇主声量极低，样本不足必须标注，不能默认推荐。
  • 渠道单一：看准、BOSS 点评、知乎、贴吧、微博未接入；offer 选择类专题无数据。
  • 时效：部分评价为 2022–2024 年；最新两天目标公司零新帖，无法验证「当下」口碑。

cd F:/despseekharness/crawler

八、边界

  • 数字来自本地抓取产物的实际文件统计，不是站点自报计数；帖子量按正文去重，覆盖时间已剔除未来日期。
  • 不含 Cookie / 账号 / token 与具体风控阈值；cookies/ · profiles/ 已在 .gitignore 排除。
  • 采集内容涉及真实员工薪资与工时评价，产物只落本地工作区，公开发布前须核查脱敏。
  • 风控是终止信号：遇验证码/登录墙立即停，不重试、不换账号、不换后端。
